#### EasyTier 全球通
欢迎使用EasyTier全球通，这是一个公共的EasyTier节点列表，可以通过下载配置文件导入和http节点的方法使用。本节点列表在国内效果较好，在国外略次。

### 下载配置文件导入

下载仓库中的`ruyue-easytier-global-pass.cfg`文件并导入即可。

### http节点

在EasyTier中写入节点：

```plaintext
#速度优先
http://ruyue713.github.io/ruyue-easytier-global-pass
#安全/特殊环境优先
https://ruyue713.github.io/ruyue-easytier-global-pass
```

### 问题反馈

提交Issue或PR（如修改文件）即可。
